# Documentos de apoio

Os PDFs e o arquivo Material de apoio foram fornecidos pelo professor e estão aqui como referência. O circuito PNG é a captura enviada para este projeto.

As credenciais e identificadores da estufa deste projeto foram personalizados; os valores presentes nos exemplos do professor não são usados na ponte, no firmware nem no provisionamento.

## Observação sobre o circuito

Na captura, os pinos VCC do DHT22 e dos módulos analógicos parecem sem ligação. Antes de executar, confira os rótulos no Wokwi e conecte cada VCC à alimentação adequada, mantendo GND comum. O código espera solo em GPIO34, LDR em GPIO35 e DHT22 em GPIO4.
